# Disponibilidade de Ativos - Sistema Siges

## Visão Geral

O módulo de **Disponibilidade de Ativos** oferece uma visão consolidada da disponibilidade operacional de todos os ativos da empresa, expressa em percentual (0% a 100%).

### Conceito de Disponibilidade

A disponibilidade é calculada com base na **soma ponderada dos coeficientes de participação** de ativos dentro de um mesmo setor. Cada ativo possui um peso relativo que representa sua importância na capacidade operacional total do setor.

#### Exemplo Prático: Setor de Bombeamento

Se uma unidade possui dois grupos motor-bomba com características idênticas (potência, vazão, etc.), a importância relativa de cada ativo é de **50%** em relação ao total de ativos disponíveis do setor.

- **Ativo A:** 50% de participação (`asset_available_rate = 0.5`)
- **Ativo B:** 50% de participação (`asset_available_rate = 0.5`)
- **Disponibilidade do Setor:** Soma dos ativos operacionais × seus coeficientes

## Estrutura Organizacional

### Hierarquia de Ativos

Os ativos são organizados seguindo a estrutura:

```
Unidade (units)
  └── Tag do Ativo (cfg_assets_tags)
        └── Sub-Tag do Ativo (cfg_assets_tags_subs)
              └── Configuração (cfg_units_assets_tags)
                    └── Registros de Disponibilidade (assets_available)
```

Cada configuração de ativo dentro de uma unidade possui características técnicas específicas que devem ser cadastradas no sistema.

## Tipos de Setores e Características

| Setor | Características Técnicas Suportadas |
|-------|-------------------------------------|
| **Bombeamento** | Vazão (`flow_rate`), Potência (`power`), Pressão (`pressure`) |
| **Geração Elétrica** | Potência (`power`), Tensão (`voltage`), Amperagem (`amperage`) |
| **Subestação** | Tensão (`voltage`), Amperagem (`amperage`), Potência (`power`) |
| **Entrada de Energia** | Tensão (`voltage`), Amperagem (`amperage`) |
| **Edificações** | Sem características técnicas específicas |
| **Comportas** | Pressão (`pressure`) |

## Cálculo de Disponibilidade

### Fórmula Básica (Setor sem Dependências)

```
Disponibilidade do Setor = Σ (last_is_available × asset_available_rate)
```

**Onde:**
- `last_is_available`: 1 se disponível, 0 se indisponível
- `asset_available_rate`: Coeficiente de participação (0.0 a 1.0)

### Exemplo Prático

**Setor de Bombeamento com 3 ativos:**

| Ativo | `asset_available_rate` | `last_is_available` | Contribuição |
|-------|------------------------|---------------------|--------------|
| Bomba A | 0.40 (40%) | true (1) | 0.40 |
| Bomba B | 0.40 (40%) | true (1) | 0.40 |
| Bomba C | 0.20 (20%) | false (0) | 0.00 |

**Disponibilidade do Setor = 0.40 + 0.40 + 0.00 = 0.80 (80%)**

### Query SQL para Cálculo

```sql
SELECT 
  unit_id,
  asset_tag_id,
  SUM(
    CASE 
      WHEN last_is_available = true THEN asset_available_rate 
      ELSE 0 
    END
  ) AS sector_availability
FROM cfg_units_assets_tags
WHERE is_deleted = false
  AND is_active = true
GROUP BY unit_id, asset_tag_id;
```

## Dependências entre Setores

### Modelagem de Dependências (Proposta Futura)

Para implementar dependências entre setores (ex: Bombeamento depende de Subestação), será necessário criar uma tabela adicional:

```sql
create table public.cfg_assets_dependencies (
  id bigint generated by default as identity not null,
  dependent_asset_tag_id bigint not null,  -- Setor dependente (ex: Bombeamento)
  required_asset_tag_id bigint not null,   -- Setor requerido (ex: Subestação)
  is_redundant boolean default false,      -- Se é uma dependência redundante (ex: Gerador)
  priority smallint default 1,             -- Prioridade (1 = primária, 2 = secundária)
  constraint cfg_assets_dependencies_pkey primary key (id),
  constraint cfg_assets_dependencies_dependent_fkey foreign key (dependent_asset_tag_id) references cfg_assets_tags (id),
  constraint cfg_assets_dependencies_required_fkey foreign key (required_asset_tag_id) references cfg_assets_tags (id)
);
```

### Fórmula com Dependências

```
Disponibilidade Efetiva = Disponibilidade do Setor × MAX(Disp. Primária, Disp. Redundante)
```

**Exemplo:**
- Bombeamento: 80%
- Subestação (primária): 100%
- Gerador (redundante): 50%

```
Disponibilidade Efetiva = 0.80 × MAX(1.00, 0.50) = 0.80 × 1.00 = 80%
```

Se a Subestação cair para 0%:

```
Disponibilidade Efetiva = 0.80 × MAX(0.00, 0.50) = 0.80 × 0.50 = 40%
```

## Glossário

| Termo | Descrição |
|-------|-----------|
| **Asset Tag** | Categoria principal do ativo (ex: "Bombeamento", "Geração") |
| **Asset Sub-Tag** | Subcategoria do ativo (ex: "Bomba Centrífuga", "Gerador Diesel") |
| **Coeficiente de Participação** | Peso relativo do ativo na capacidade total do setor (`asset_available_rate`) |
| **Disponibilidade** | Percentual de capacidade operacional disponível (0% a 100%) |
| **Setor** | Agrupamento lógico de ativos por função (equivalente a `asset_tag`) |
| **Unidade** | Instalação física (ex: ETA, ETE, Estação de Bombeamento) |
