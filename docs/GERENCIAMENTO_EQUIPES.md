# Gerenciamento de Equipes e Departamentos

## Como Associar Equipes aos Departamentos

Existem **3 maneiras** de associar equipes aos departamentos:

### 1. Criar Nova Equipe em um Departamento Específico

**Passos:**
1. Navegue até a empresa desejada
2. Clique em um departamento para abrir os detalhes
3. Na aba "Equipes", clique no botão **"+"** (adicionar)
4. Preencha o formulário:
   - **Nome da Equipe**: Ex: "Desenvolvimento Frontend"
   - **Código**: Ex: "DEV-FE"
   - **Status**: Ativo/Inativo
5. Clique em **"Salvar"**

A equipe será automaticamente associada ao departamento atual.

### 2. Mover Equipe para Outro Departamento (Editar)

**Passos:**
1. Navegue até o departamento onde a equipe está
2. Na aba "Equipes", clique na equipe que deseja mover
3. Clique no botão **"Editar"**
4. No formulário de edição, selecione o novo departamento no campo **"Departamento"**
5. Clique em **"Salvar"**

A equipe será movida para o novo departamento selecionado.

### 3. Criar Equipe e Escolher Departamento

**Passos:**
1. No formulário de criar equipe (quando há múltiplos departamentos disponíveis)
2. Preencha os dados da equipe
3. Selecione o departamento desejado no dropdown **"Departamento"**
4. Clique em **"Salvar"**

---

## Como Desassociar/Remover Equipes

### Excluir Equipe

**Passos:**
1. Navegue até a equipe que deseja excluir
2. Nos detalhes da equipe, clique no botão **"Excluir"**
3. Confirme a exclusão na caixa de diálogo

⚠️ **ATENÇÃO**: A exclusão é permanente e remove a equipe completamente do sistema.

## Estrutura no Banco de Dados

### Tabela: `cfg_teams`

```sql
CREATE TABLE public.cfg_teams (
    id bigint generated by default as identity not null,
    department_id bigint not null,  -- Chave estrangeira para cfg_departments
    code character varying null,
    description character varying null,
    is_available boolean null default true,
    created_user_id bigint null,
    created_at timestamp without time zone null default now(),
    updated_user_id bigint null,
    updated_at timestamp without time zone null,
    deleted_user_id bigint null,
    deleted_at timestamp without time zone null,
    is_deleted boolean null default false,
    version character varying null default 'live'::character varying,
    constraint teams_pkey primary key (id),
    constraint teams_department_fkey foreign key (department_id) 
        references public.cfg_departments(id) on delete cascade
);
```

### Relacionamento

- **Uma equipe pertence a UM departamento** (relacionamento 1:N)
- O campo `department_id` faz essa associação
- Se um departamento for excluído, todas as suas equipes também serão excluídas automaticamente (`ON DELETE CASCADE`)

## Operações Disponíveis via API

### 1. Criar Equipe
```typescript
await dataService.createTeam({
    name: 'Nome da Equipe',
    code: 'CODIGO',
    departmentId: 'ID_DO_DEPARTAMENTO',
    status: 'active'
});
```

### 2. Atualizar Equipe (Mover para outro departamento)
```typescript
await dataService.updateTeam('ID_DA_EQUIPE', {
    name: 'Novo Nome',
    code: 'NOVO_CODIGO',
    departmentId: 'NOVO_ID_DEPARTAMENTO', // Muda o departamento
    status: 'active'
});
```

### 3. Excluir Equipe
```typescript
await dataService.deleteTeam('ID_DA_EQUIPE');
```

### 4. Listar Equipes de um Departamento
```typescript
const teams = await dataService.getTeamsByDepartment('ID_DO_DEPARTAMENTO');
```

### 5. Listar Todas as Equipes
```typescript
const teams = await dataService.getTeams();
```

1. **Ver todas as equipes** de um departamento
2. **Editar equipes** individualmente para movê-las
3. **Verificar** a nova estrutura nos detalhes do departamento

### Limpar Equipes Antigas

1. **Navegar** até a equipe
2. **Verificar** se não há membros ou dados importantes
3. **Excluir** com confirmação
