# Plano: Tela de Listagem de Workers por Unidade

**Status:** rascunho para análise · **Data:** 27/09/2026

## 1. Objetivo

Tela nova que lista as **unidades da `company_id` do usuário logado**, permitindo
incrementar/decrementar (`+`/`−`) a quantidade de **workers** de cada unidade.

## 2. Regras aprovadas

| Definição | Decisão |
|---|---|
| Persistência | Tabela nova `unit_workers` (unit_id, company_id, workers) |
| Valor padrão | **1** (unidade sem linha na tabela exibe 1) |
| Limites | Sem mínimo → pode chegar a **0** (− desabilitado em 0); sem máximo informado |
| Acesso | Nova screen, item no **menu lateral (Sidebar)** |
| Permissão | Bloqueio por `PermissionsContext`, routeKey `unit_workers` |

## 3. Banco de dados — `dev/supabase/migrations/20260927_create_unit_workers.sql`

Aplicada **manualmente no SQL Editor do Supabase** (AGENTS.md). Idempotente.

### 3.1 Tabela

```sql
CREATE TABLE public.unit_workers (
    id              bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    unit_id         bigint NOT NULL UNIQUE REFERENCES public.units(id) ON DELETE CASCADE,
    company_id      bigint NOT NULL REFERENCES public.cfg_companies(id) ON DELETE CASCADE,
    workers         integer NOT NULL DEFAULT 1 CHECK (workers >= 0),
    created_at      timestamptz NOT NULL DEFAULT now(),
    updated_at      timestamptz NOT NULL DEFAULT now(),
    created_user_id bigint,
    updated_user_id bigint
);
ALTER TABLE public.unit_workers ENABLE ROW LEVEL SECURITY;

-- policies no padrão das migrations 20260915/20260926:
CREATE POLICY "authenticated can select unit_workers" ON public.unit_workers FOR SELECT TO authenticated USING (true);
CREATE POLICY "authenticated can insert unit_workers" ON public.unit_workers FOR INSERT TO authenticated WITH CHECK (true);
CREATE POLICY "authenticated can update unit_workers" ON public.unit_workers FOR UPDATE TO authenticated USING (true);
CREATE POLICY "authenticated can delete unit_workers" ON public.unit_workers FOR DELETE TO authenticated USING (true);

CREATE INDEX idx_unit_workers_company ON public.unit_workers(company_id);
```
